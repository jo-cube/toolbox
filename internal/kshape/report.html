How to read this report

Observed, not authoritative.
Density and gaps describe the supplied first-to-last offset spans. They do not reveal broker watermarks, missing causes, or records outside the stream.

Visible versions, not write history.
Key churn is surviving keyed records divided by estimated distinct keys. It cannot count versions removed before this stream was observed.

Logical payload, not disk.
Payload sizes exclude Kafka overhead, compression, indexes, replicas, and broker storage. Key estimates use HLL with theoretical relative error {{.HLLRelativeError}}.
